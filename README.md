# Nutrition

Tyler's daily meal plan as a phone-first app: daily totals, meals sorted by time, foods you can edit in place
(servings, macros, micronutrients), and saved copies you can view and compare.
It installs to the iPhone Home Screen and works offline.

**Install:** open https://jtnicastro.github.io/nutrition/ in Safari → Share → *Add to Home Screen*, then open it from the new icon.

- Your plan and saved copies are stored on the phone only. Back up from **Saved copies → Back up everything**.
- `seed.json` is the starting plan loaded on first launch (from NutritionV06.14.26.xlsx, as last edited in the Claude version).
- Font: Archivo, SIL Open Font License 1.1 (see `fonts/`).
